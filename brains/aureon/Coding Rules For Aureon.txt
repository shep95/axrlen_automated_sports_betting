Coding Rules For Aureon:

I. Core Principles for All Code
System 2 Forcing: Before coding, explicitly list distinct logical steps, then explain potential pitfalls for each. Only then commence coding.
Expert Domain Specificity: Tailor coding approach to the domain (e.g., memory-aware for systems, security-first for web, scalability for data).
Negative Constraints:
NEVER invent library functions that do not exist.
NEVER use deprecated patterns when modern alternatives are available.
NEVER write code that loads entire datasets into memory when streaming is feasible.
Code Quality Standards:
All code MUST be production-grade, typed, and documented.
Adhere to DRY (Don't Repeat Yourself) principles.
Prioritize guard clauses over nested if/else statements.
Implement proper error handling with specific exception types.
Adopt a security-first mindset: use parameterized queries, validate all inputs, and trust NO input.
Recursive Self-Correction (The Critic-Actor Loop):
After initial code, act as a Senior Code Reviewer: identify O(n²) loops, security flaws, and poor naming.
Test against at least 10 edge cases (empty inputs, huge files, unicode, network timeouts, null values).
Rewrite code incorporating all feedback.
Calculate Big O notation; if worse than O(n log n), optimize without prompting.
Lore-to-Code Pipeline: Every variable name, string, and UI label MUST reflect the project's world/context. Avoid generic terms.
II. Architecture & Design Directives
Asynchronous-First Architecture: All AI model interactions MUST be abstracted through a 'ModelGateway' interface for provider-agnosticism.
Resource Budgets: Implement strict max_tokens and max_retries in every service constructor.
N+1 Inference: AVOID by batching requests.
Defensive Prompting: Isolate user content in XML blocks.
Idempotence & Traceability: Ensure all stateful operations are idempotent and include a correlation_id for distributed tracing.
Atomic Design & Headless Logic: Strictly enforce this for frontend. Business logic and AI-stream handling MUST reside in custom hooks, NEVER in JSX components.
Schema-First Approach: Validate all data ingress at the architectural boundary using a schema-first approach before it interacts with internal business logic.
III. Security Protocols
Zero-Trust Architecture: Validate all inputs.
Constant-Time Comparisons: Use for secrets.
Encryption: Encrypt all state backends and transit paths.
Least Privilege: Enforce IAM policies with specific Resource ARNs; reject Action: *.
Immutable Infrastructure: Use Packer/Docker for images rather than remote-exec provisioning.
Input Validation: Validate all inputs for injection vectors in user-data scripts.
Credential Handling:
NEVER hardcode credentials; use OIDC or Vault integration.
If a secret MUST be handled, reference it via a Secret Manager ARN, NEVER an environment variable string.
NEVER store credentials in LocalStorage; use HttpOnly or Memory state.
Sanitization: Sanitize all dynamic LLM outputs using DOMPurify-like logic to prevent XSS.
PII Stripping: Strip PII/Sensitive context from all frontend loggers.
Cryptographic Key Sizes: Enforce a minimum RSA key size of 4096 bits.
Nonces: Use deterministic construction for AES-GCM or XChaCha20-Poly1305.
Memory Scrubbing: Utilize memory-scrubbing types for all sensitive cryptographic material.
Constant-Time Equality Checks: For authentication tag and signature verifications.
CSPRNGs: Cryptographic entropy MUST be sourced from a CSPRNG.
IV. Performance & Optimization Mandates
Big O Notation: Calculate for every code block; rewrite if worse than O(n log n).
Chaos Monkey Injection: Assume APIs have 50% packet loss and 2000ms latency. Implement Retry with Exponential Backoff. Handle disk full, memory overflow, and network rot gracefully.
Streaming-First: Optimize for token-by-token rendering using memoization and localized state to prevent layout thrashing.
Token Batching: Any component displaying AI streaming text MUST utilize token-batching/requestAnimationFrame; NEVER sync state per-character.
State Throttling: State updates during streaming MUST be throttled to 16ms intervals or use requestAnimationFrame.
Memory Optimization: Utilize TypedArrays (Float32Array, Float64Array) for high-frequency feature storage. Eliminate array spread operators and concatenations in hot paths.
Cache Management: Generate cache keys using fixed-size cryptographic hashes. Enforce cache eviction via LRU or LFU strategies.
Decoupling: Decouple expensive data processing and collection filtering from the critical request path by pre-calculating and caching results.
Concurrency: Prohibit empty-loop busy-waiting; utilize platform-native poll, nanosleep, or futex syscalls.
Data Pipeline Efficiency: Eliminate O(N) process forking by using streaming processors. Keep FIFOs and stream pipes open across read/write cycles.
V. Debugging & Reliability Standards
The Scout (Context Gathering): Identify stack trace, map related code files, consider recent changes, bundle error + definition + usage.
The Diagnostician (Root Cause Analysis): Do NOT fix symptoms; find the disease. Use the "Rubber Duck" Protocol. Generate a "Hypothesis Tree."
The Surgeon (The Fix): Apply the patch with precision. Verify with a mental test case. Explain WHY the fix is safe.
Reflection Loop: Explain intended logic, root cause, propose 3 solutions, select best, deliver.
Isolation Chamber: Extract the failing function into a standalone context with hardcoded inputs.
Error Boundaries: Every AI-generated content block MUST be wrapped in a local ErrorBoundary to prevent model hallucinations from crashing the SPA.
Retry-CircuitBreaker: Every LLM interaction MUST be wrapped in a Retry-CircuitBreaker pattern with a 30s timeout.
Schema Strictness: Use Pydantic V2 for all data modeling; NEVER trust raw dictionary access for model outputs.
Traceability: Inject an x-aureon-trace-id in every internal module call for recursive debugging.
Crash-Safe Bootstrap: Implement logic where orphaned temporary files are transitioned to a recovery state for reprocessing.
VI. Frontend-Specific Directives
UI Frameworks: Use Tailwind CSS with Radix UI primitives ONLY.
Accessibility: Every interactive custom element MUST have an aria-label and support keyboard Enter/Space triggers.
Responsiveness: Use Container Queries (@container) for dashboard widgets rather than viewport media queries.
UI State: Prioritize 'Immutable UI State' and 'Atomic Design' principles.
Content Visibility: Use Content-Visibility: Auto for long AI message lists.
Loading Patterns: Implement 'Skeleton Loading' patterns for all async AI calls.
DOM Sanitization: All AI-generated markdown MUST be sanitized via DOMPurify before rendering.
Anti-AI-Slop Directive:
Output is REJECTED if: generic fonts as primary, purple/blue AI gradients, centered single-column layouts, generic card grids, buttons without hover/active/focus states, instant show/hide without animation, Lorem ipsum, or "Submit" labels.
ZERO placeholder content (no Lorem ipsum, no TODO).
COMPLETE, RUNNABLE code, not fragments.
Visually competitive with $1B+ products.
Every interaction MUST feel physical.
MUST work on EVERY device.
VII. Backend & Data Engineering Directives
Vector-Relational Cohesion: Prioritize. NEVER generate raw vector search queries without explicit Row Level Security (RLS) predicates.
Fetch-then-Close: Use for any AI-related data fetching to prevent connection pooling deadlocks.
Vector Indexes: All vector indexes MUST include quantization (PQ) by default unless low-latency/high-precision is explicitly requested.
Upsert Logic: Use with conflict resolution for all high-velocity ingestion.
JSONB Schema Validation: Enforce using CHECK constraints for unstructured AI metadata.
Data Pipeline Idempotence: All state transitions and writes MUST be idempotent.
VIII. Computational Linguistics Protocols
Context-Isolation Pattern: Every external string MUST be treated as untrusted and wrapped in unique XML delimiters.
Hard-Stop Token Calculator: All LLM-facing code MUST implement a 'Hard-Stop' token calculator.
Regex Audits: Any regex-based text cleaning MUST be benchmarked against 1k repeated characters to prevent ReDoS.
Pydantic for NLP Output: Use for all NLP output structures; naked eval() or json.loads() on model output without secondary schema-validation is strictly prohibited.
NFKC Normalization: Enforce on all text inputs before embedding generation or string comparison.
Stream-First Linguistic Architecture: NEVER assume constant string length; use byte-offsets for multi-byte character safety.
Decouple Tokenization: Decouple from feature extraction using the Strategy pattern.
Lazy Loading/Memoization: For heavy model weights and repetitive morphological transformations.
IX. Concurrency & Parallelism Mandates
Atomic Primitives: Use for "check-then-act" sequences and shared counters. Replace boolean-based flag checks with hardware-level atomic primitives.
Thread-Safe State: Maintain a persistent, thread-safe state for Task Graphs and Dependency Registries.
Atomic Operations: Reserve unique identifiers and sequence numbers using Atomic::fetch_add BEFORE validation logic.
Non-Blocking Execution: Avoid blocking execution threads with sleep or wait commands; utilize non-blocking schedulers or event-driven triggers.
Mutex Guards: Release before signaling Condition Variables.
Resource Management: Implement the Drop trait or use "Scope Guards" for all resource managers to ensure graceful shutdown.
True Parallelism: Enforce via OS-level threads or worker pools rather than sequential round-robin loops.
